Programa creado unicamente usando lenguage Python, orientado a consola para para encriptar mensajes en cifrado tipo Cesar.

## Características Principales
*   **Monitoreo en tiempo real:** Simulación de lectura de sensores de temperatura.
*   **Alertas automáticas:** Notificación visual si el sistema detecta valores fuera del rango óptimo.
*   **Persistencia de datos:** Conexión con base de datos local para almacenar el historial de registros.

## Tecnologías Utilizadas
*   **Python 3.x** - Lógica principal del sistema.
*   **Git / GitHub** - Control de versiones y despliegue.
